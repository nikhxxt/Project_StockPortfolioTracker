# 📈 Stock Portfolio Tracker

A simple **stock portfolio tracking web app** built with Python and Streamlit. It allows users to add/remove stocks, track shares and purchase prices, and view current market values using the Alpha Vantage API.

## 🚀 Live Demo

[Stock Portfolio Tracker · Streamlit](https://projectstockportfoliotracker-womclutid84ovm9yb6cappj.streamlit.app/)

## ✨ Features

- Add and remove stocks
- Track shares and purchase prices
- Calculate average cost basis
- Fetch current stock prices
- Validate stock ticker symbols
- Calculate current and total portfolio value

## 🛠️ Tech Stack

**Python · Streamlit · Requests · Alpha Vantage API**
